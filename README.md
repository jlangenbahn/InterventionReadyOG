# InterventionReadyOG

Basic React (Vite) + AWS Amplify Gen 2 hello world app.

## Setup

```bash
npm install
npx ampx sandbox
npm run dev
```

`npx ampx sandbox` deploys a personal cloud sandbox and writes `amplify_outputs.json` (gitignored). Run that before `npm run dev`.

## Scripts

- `npm run dev` — start the development server
- `npm run build` — build for production
- `npm run preview` — preview the production build
- `npx ampx sandbox` — deploy/watch Amplify Gen 2 backend
